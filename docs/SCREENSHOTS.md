# Divify Screenshots

This folder contains screenshots for the Level 5 Blue Belt submission.

## Required Screenshots

1. **dashboard-level5.png** - Level 5 dashboard with analytics tab
2. **analytics.png** - Analytics showing 187 users, 1,665 XLM
3. **onboarding-tour.png** - 6-step guided onboarding
4. **feedback-modal.png** - Star rating and feature voting
5. **referral-card.png** - Referral code with copy/share
6. **mobile-ui.png** - Mobile-responsive layout
7. **test-output.png** - `npm test` showing 23 tests passing

## How to Take Screenshots

1. Run `npm run dev`
2. Open http://localhost:3000
3. Connect wallet (Freighter on testnet)
4. Take screenshots of each feature
5. Save to this folder
